# Eximion: Opening Case in one click (UX concept)

Concept of the first screen after "Try it free" on Eximion championship landings.

**Problem.** Landings promise an undiagnosed patient in about 8 minutes with no sign-up. Today the click leads through about 1,500 words of accreditation text, a hub with Duel first, a patient list without the "Opening Case" label and one more modal: 5 screens before the first clinical decision.

**Solution.** One start screen with the promised patient, time, credit and a single "Start the case" button. Disclosures stay before the activity in a compact panel with expandable sections. Name and email come after the debrief, when the credit is earned.

**Live prototype:** https://maksim431.github.io/eximion-opening-case/
